# Engage logo

The Engage mark and primary lockup as vector artwork, redrawn from the existing brand logo (the artwork is the same as on the Engage website).

| File | Use |
| --- | --- |
| `Engage-Logo-FullColour.svg` | Primary lockup (icon and wordmark), full colour. Use this wherever vector is supported. |
| `Engage-Logo-FullColour.eps` | The same lockup as an EPS (Level 3, RGB, outlined type) for print suppliers and event organisers. |
| `Engage-Logo-FullColour-2000px.png` | The same lockup as a 2000 px wide PNG with a transparent background. |
| `EngageIcon.svg` | The icon alone, full colour, on a 1024 px square artboard. |
| `engage-icon-dark.svg` | The icon alone in charcoal (`#222222`), for single-colour or neutral layouts. |

## Colour

- Wordmark: `#15385B`.
- Icon gradient: five stops from `#15385B` to `#00001A`.
- Charcoal icon: `#222222`.

## Rules

- The full-colour lockup is for **light backgrounds** only. The navy wordmark does not hold up on dark backgrounds, and no reversed version is included here.
- Do not recolour the full-colour mark, stretch it, or add effects.
- Do not place the Engage mark next to a customer's logo as if it were one lockup.
- The `Logo` component in `engage-appi-design-system` draws the same lockup in charcoal for documents built with that system.

The wordmark is drawn as outlines, so no font is needed to display any of these files.
